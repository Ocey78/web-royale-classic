# Web Royale Classic 0.50.1

Higher resolution compatible artwork from the supplied Clash Royale 16.402.2
package replaces portraits and 83 existing troop/building scenes. The historical
102-card game data, arenas, progression and replay engines are retained.

Directional exports retain their original transforms. Source rotation flags only
override existing renderer settings when explicitly present, preserving Flying
Machine and other authored orientation settings.

Verified locally: 1,268 tests passed. The built release was opened in Chrome;
144 troop drawings, both teams, idle/run/attack animation, collection, shop,
battle and Touchdown were checked without script errors or failed game assets.
Release version is 0.50.1; gameplay snapshot is 3.2557.2.

The browser simulation is independently implemented. Online multiplayer and
additional modern seasonal tower skins are not included in this release.
